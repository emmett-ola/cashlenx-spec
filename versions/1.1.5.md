## Website test entry point

`scripts/test.sh` runs the same TypeScript project check the build runs
(`tsc -b`) and then `bun test`. The suite renders the page to a string with
`react-dom/server`, so it needs no DOM library and no new dependency:

| Check | What it proves |
| --- | --- |
| overview at the default hash | the hero slogan, the product section and the primary navigation render |
| `#/api-reference` | the API reference page renders its own endpoint surface (`POST /cash/expense`) |
| `#/cli-reference` | the CLI reference page renders its own command surface |
| unknown hash | falls back to the overview instead of an empty page |
| rendering never calls `fetch` | a throwing `fetch` stub is installed and the render still succeeds, so the site cannot claim data it does not own |

Five tests, five passing. `test/types.d.ts` declares `bun:test` for the editor;
the test directory sits outside `tsconfig.json` and is never part of the build.

## CLV retirement in Jira

Using `twg` against `macacloud.atlassian.net`, every Idea in the Jira Product
Discovery project `CLV` was archived by setting the native `想法已归档` /
`Idea archived` field (`customfield_10106`) to `Yes`. The Ideas stay readable;
none was deleted, moved or re-summarised. `CLV-7` was archived first and read
back to confirm the field took a value before the rest were processed.

All 21 Ideas reported `archived` and none failed. Confluence still carries the
old wording that CLV is the version authority: three `twg` updates of page
52166678 (one full-body, two targeted `--edits`, each `--dry-run` validated)
returned `internal_error` and left the page unchanged. The prepared replacement
is recorded in `backlog/atlassian-clv-archival.md`.

## MySQL expired

`facts/deployment-profiles.md` now states MySQL support expired on 2026-11-20:
MongoDB is the only supported profile, no new MySQL work or compatibility
acceptance is written, and the existing `*.sql` sequence, `DB_TYPE=mysql` path
and dependency project stay as legacy so an existing installation can still
start. Reinstating MySQL needs an owner decision and a version.
