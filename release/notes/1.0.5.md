# CashLenX 1.0.5

Status: release candidate prepared on `develop`; shared-environment acceptance
and branch promotion are recorded separately.

CashLenX 1.0.5 makes the localized entry experience deterministic. The App
bundles and preloads Simplified and Traditional Chinese interface fonts before
the first visible frame, and entering Demo mode preserves the language selected
on the unauthenticated screen. The Server adds repeatable, secret-safe Testing
acceptance and unambiguous Docker and nerdctl container inspection.

Affected runtime versions:

- App: `1.0.5+11`
- Server and OpenAPI: `1.0.5`
- Website: remains `1.0.3`; no Website source or behavior change is selected
  for this patch.

The canonical Testing API origin is
`https://test-api.cashlenx.com/api/v1`. The previous candidate hostnames remain
cleanup references only.

No database schema or data migration is introduced after the delivered 1.0.4
boundary. Existing MongoDB and MySQL migration identities and checksums are
unchanged. Testing and Production deployment, SMTP configuration, release tags,
artifact publication, and production acceptance require their own recorded
evidence.
