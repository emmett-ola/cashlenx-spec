# CashLenX 1.1.1

Status: App release candidate validation is in progress. No Testing promotion,
release tag, publication, deployment, database execution, or production
acceptance is implied.

CashLenX 1.1.1 is an App-only UI quality release. It restores localized
semantics across core controls, makes Profile and transaction detail
URL-addressable, applies coherent semantic light and dark surfaces, preserves
Budget calculations at the selected currency's minor-unit precision,
constrains transaction entry to the mobile canvas on wider hosts, respects
reduced-motion preferences, and localizes Budget period labels consistently
with Statistics.

Focused regression coverage protects localized semantics, representative light
and dark routes, reduced motion, large text, direct URLs, Budget precision and
period formatting, and the add-transaction sheet at phone, tablet, and desktop
widths.

Affected runtime versions:

- App: `1.1.1+18`.
- Server and OpenAPI: remain `1.1.0`; the stable `/api/v1` and frozen `/api/v0`
  contracts are unchanged.
- Website: remains `1.0.9`; no Website source or behavior change is selected.
