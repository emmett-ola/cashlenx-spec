# CashLenX 1.0.0-rc.1

Status: untagged non-production release candidate.

This candidate establishes the stable `/api/v1` contract, preserves the frozen
`/api/v0` previous-client alias, aligns App, Server, Website, OpenAPI, and
release metadata on one semantic version, and introduces reproducible,
checksummed container artifacts for exact source revisions.

It also includes the approved single-node container profile, MongoDB primary
and MySQL compatibility rehearsal, production security baseline, durable
MongoDB migration tracking, and encrypted backup/restore-drill tooling.

This candidate is validation evidence only. It is not a stable release tag,
artifact publication, branch promotion, deployment, database migration, or
production acceptance.
