# CashLenX 1.1.3

App-only maintenance for consistent environment-driven native and container
configuration, tracked by [CLV-21](https://macacloud.atlassian.net/browse/CLV-21)
and [CLX-103](https://macacloud.atlassian.net/browse/CLX-103).

The native launcher selects a repository-local `ENV_FILE`, forwards only the
five public App/API settings, honors explicit shell overrides, and preserves
empty API ports. Configured device addresses are used unchanged. Android
network access is declared in the main manifest; HTTP is permitted only for
debug builds. The previously uncommitted emulator-address rewriting, Gradle
migrator flags, and generator-hash noise are excluded.

Affected runtime versions:

- App: `1.1.3+19`.
- Server and OpenAPI: retain `1.1.0`.
- Website: retains `1.0.9`.

App source: `142cd57d077543afd5b6c1b8e98750d70fc35226` on `develop`.
Validation: App analysis passed; all 164 Flutter tests and six additional
HTTPS/empty-port platform checks passed. Native-launcher and Docker/nerdctl
lifecycle smoke checks, Android manifest policy checks, and real Docker Compose
default/empty-port expansion checks passed. Native Android builds and device
acceptance have not been performed.

No API, database, schema, migration, initialization, backup, restore, or
persistence change is introduced. No database change required.

This boundary covers implementation and synchronization of local and remote
`develop` only. Testing/main promotion, the full release-candidate gate, tags,
runtime deployment, and production acceptance remain pending separately.
Android manifest checks and unit tests do not establish device acceptance.
