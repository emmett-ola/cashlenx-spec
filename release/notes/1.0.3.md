# CashLenX 1.0.3

Status: untagged source delivery completed through the v1.0.4 main promotion.

CashLenX 1.0.3 introduces the unified camera-and-cash brand identity across the
Flutter App and public Website. The App now uses the supplied artwork for
Android adaptive and round launchers, iOS light/dark/tinted appearances,
macOS, Windows, Flutter Web/PWA metadata, web bootstrap, splash,
authentication, first-login setup, and About. The Website uses the matching
mark in its header, browser icons, Apple touch icon, and installable web-app
metadata.

The Server participates only in coordinated product-version metadata. This
release does not change Server behavior, API routes, OpenAPI schema, database
schema, migrations, stored data, secrets, or deployment configuration.

The exact v1.0.3 App, Server, and Website sources passed Testing promotion.
The Website source was later promoted unchanged to `main` as the Website
component of the v1.0.4 product delivery, while App and Server advanced to
their v1.0.4 candidates before `main` promotion. No v1.0.3 tag was created and
no separate v1.0.3 production acceptance was recorded.
