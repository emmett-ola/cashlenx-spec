# CashLenX 1.1.0

Status: App and Server release candidate prepared for Testing and Production
branch promotion; publication, runtime deployment, and acceptance evidence are
recorded separately.

CashLenX 1.1.0 delivers a coherent email-verification journey. Registration
now presents the destination email as read-only context, focuses the six-digit
code entry, retains resend feedback, and provides localized Confirm and Return
to edit email actions. Purpose-scoped verification messages are sent as a
restrained, responsive CashLenX HTML email with a prominent selectable code,
clear expiry guidance, escaped dynamic values, and no active or tracking
content.

The cumulative App candidate also contains the completed 1.0.9 and 1.0.10
client work that has not previously reached the production branch: stable
dashboard range context, bounded About presentation, the approved localized
slogan, independent App and API release identities, consistent selected
currency presentation, and exclusive Settings ownership of user preferences.

Affected runtime versions:

- App: `1.1.0+17`
- Server and OpenAPI: `1.1.0`; the stable `/api/v1` and frozen `/api/v0`
  contracts are unchanged.
- Website: remains `1.0.9`; no Website source or behavior change is selected
  for 1.1.0.

No database schema, migration, initialization, backup, restore, or persistence
change is introduced. Existing MongoDB and MySQL migration identities and
checksums are unchanged. App static Web publication is branch-driven after a
successful App workflow. Server branch promotion does not deploy a runtime.
No release tag, Server runtime deployment, database execution, provider email,
or whole-product production acceptance is implied by branch promotion.
