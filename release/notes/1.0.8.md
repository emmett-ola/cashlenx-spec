# CashLenX 1.0.8

Status: App release candidate prepared for Testing and Production branch
promotion; publication and acceptance evidence are recorded separately.

CashLenX 1.0.8 makes frequent finance activity easier to reach. The complete
transaction ledger is now a primary destination, Home's recent-activity See All
action opens that same destination, and Category Management has moved under
Settings > Resource Management. The dashboard now uses a compact Financial
Insights entry instead of duplicating the category chart.

The App also includes the previously prepared legacy cash-flow presentation
reconciliation and complete Simplified and Traditional Chinese font assets.

Affected runtime versions:

- App: `1.0.8+14`
- Server and OpenAPI: remain `1.0.7`; no Server source or behavior change is
  selected for this patch.
- Website: remains `1.0.3`; no Website source or behavior change is selected
  for this patch.

No database schema or data migration is introduced. Existing MongoDB and MySQL
migration identities and checksums are unchanged. No Server deployment,
database execution, release tag, or whole-product production acceptance is
implied by App branch promotion or static Web publication.
