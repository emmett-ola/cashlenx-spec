# CashLenX 1.0.4

Status: untagged delivery candidate selected for Testing promotion.

CashLenX 1.0.4 fixes category presentation persistence and yearly monthly
statistics completeness. Category `emoji` and `bg_color` values now remain
consistent through API requests, MongoDB and MySQL storage, list/detail/tree
responses, and backup/restore. The App now renders an ordered January through
December comparison, fills compatible missing data with zero values, and keeps
all localized month labels visible at compact widths.

Affected runtime versions:

- App: `1.0.4+10`
- Server and OpenAPI: `1.0.4`
- Website: remains `1.0.3`; no Website source or behavior changes are selected
  for this patch.

Database migration `017` adds category presentation fields with safe defaults
for existing MongoDB and MySQL records. Disposable migration, persistence,
rollback, ordering, and UTF-8 initialization checks passed. Promotion of source
does not prove that a shared environment executed the migration.

The requested delivery action is a fast-forward promotion of App and Server
from `develop` to `testing`. The App testing push publishes its branch-specific
static Web build. The Server testing push runs CI and API smoke validation but
does not deploy a runtime. This release note does not authorize a tag, `main`
promotion, production publication, runtime deployment, shared-environment
migration, or production acceptance.
